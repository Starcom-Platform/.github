# Starcom Platform

Starcom is the reference frontend of the **Earth Intelligence Network**: a decentralized, public, free-to-use
network for open-source intelligence. Starcom puts public data on a live 3D globe, and lets people publish what they
find as signed, open records over Nostr. It runs at [starcom.app](https://starcom.app).

| Repository | What it is |
|---|---|
| [`starcom`](https://github.com/Starcom-Platform/starcom) | The web app and its browser extension, Starcom Uplink. AGPL-3.0 |
| [`starcom-desktop`](https://github.com/Starcom-Platform/starcom-desktop) | The desktop host. AGPL-3.0; its code is not public yet |

**Start here:** the [README](https://github.com/Starcom-Platform/starcom#start-here) says where to begin, whether you
want to change Starcom, build an app that works with it, or run your own, public or private. The network's open
standards are in [Earth-Intelligence-Network](https://github.com/Earth-Intelligence-Network).
